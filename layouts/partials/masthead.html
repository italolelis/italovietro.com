{{- /* The masthead of a piece of writing: a kicker, the headline, the dek and one quiet meta line. Called with the page -- `{{ partial "masthead.html" . }}` -- by the post layout (layouts/posts/single.html) and the Episode layout (layouts/episodes/single.html), and the markup it writes is the same for both, so one stylesheet (_masthead.scss) and one set of post-build assertions cover every page that has one. It replaces two things. A post used to render through the theme's own template: a 1.6rem sans title that flipped in, a byline with an icon, the category with another, an ISO date, a word count. The Episode page carried a masthead of its own, inline in its layout. Italo's writing looked like a theme default beside the pages he did not write; this is the one the Episode page had, for both. The page is the interface. What each part is, for the two kinds of page there are: post Episode page kicker the category, linked to its page the show and the episode number headline the title the title dek `subtitle`, else `description` `subtitle` meta By Author · Date · N min read two lines: what it is based on; (· Updated Date, when `lastmod` released · length · when it was falls on a later day) written up The dek is the page's `subtitle` if it has one and its `description` if not. The description is also the SEO text, so a post that wants a dek of its own writes a `subtitle` and leaves the description as it is. "Updated" reads the front matter's `lastmod`, not `.Lastmod`. With `enableGitInfo` on, Hugo's default puts the date of the last commit to touch the file ahead of the front matter, so a revert of an experiment that never changed a word of a post would announce that the post was updated. A claim about currency has to be true, because the audience is checking it (ADR-0005); `lastmod` is the date Italo sets when he changes what a post says. `.Lastmod` is only the fallback for a page without one. The dates are written out in the page's language ("October 7, 2026", "7 de outubro de 2026"), with the machine-readable day in the `datetime` attribute. Every string is a `masthead.*` key in i18n/, not an `episode.*` one: what the masthead says is said once, whichever page it is on. A `div`, not a `

` here turns the masthead into a second one. */ -}} {{- $ep := .Params.episode -}}
