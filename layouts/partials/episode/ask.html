{{- /* A question put to the reader before the chapter answers it -- the New York Times habit of asking for a guess first, because an answer you committed against lands in a way a sentence does not. Declared per chapter in front matter as `ask`, and rendered straight after the chapter heading, before the summary that would give it away: type: guess -- a slider. scale (log|linear), min, max, start, ticks, unit ("%s× faster"), zero (label for the minimum, if it means "none"), answer, you/real (row labels, optional) type: choice -- buttons. options (list), answer (index from 0) Both take question, verdict, t ("mm:ss", where the recording answers it) and an optional kicker. Without JavaScript the figure renders answered: the real value or the right option marked, and the verdict shown. The controls stay `hidden` until the script takes over, so nothing is a button that does nothing. Params: page, ask. */ -}} {{- $a := .ask -}} {{- $ep := .page.Params.episode -}} {{- $t := partial "episode/seconds.html" $a.t -}} {{- $clock := partial "episode/clock.html" $t -}} {{- $href := printf $ep.at (math.Max 0 (sub $t 2) | int) -}} {{- $play := printf `▶ %s` $href (T "episode.playFrom" (dict "Clock" $clock "Where" $ep.at_label)) $clock -}} {{- $kicker := $a.kicker | default (T "episode.askKicker") -}} {{- if eq $a.type "guess" -}} {{- $log := ne $a.scale "linear" -}} {{- $min := float $a.min -}} {{- $max := float $a.max -}} {{- /* Position on the track, 0-100: the same arithmetic the script uses. */ -}} {{- $pos := 0.0 -}} {{- if $log }}{{ $pos = mul 100 (div (sub (math.Log (float $a.answer)) (math.Log $min)) (sub (math.Log $max) (math.Log $min))) }}{{ else }}{{ $pos = mul 100 (div (sub (float $a.answer) $min) (sub $max $min)) }}{{ end -}} {{- $answerLabel := cond (and $a.zero (eq (float $a.answer) $min)) $a.zero (printf $a.unit (string $a.answer)) -}} {{- else if eq $a.type "choice" -}} {{- end -}}
