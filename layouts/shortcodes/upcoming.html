An empty "Upcoming" heading says the opposite of what it is there to say, and a page that lists a conference three months after it happened is worse than a page that never claimed to look forward at all. Entries are dropped by date rather than by anyone remembering to delete them, because the failure mode is silent: nobody visits their own speaking page the week after a talk to check it aged correctly. Markup matches the talk shortcode, so the group sits in the same visual language as the two below it. Parameters: heading (required -- passed per language, since the data file holds venues and dates rather than prose). */ -}} {{- $heading := .Get "heading" -}} {{- $future := slice -}} {{- range site.Data.upcoming -}} {{- if (time.AsTime .until).After now -}} {{- $future = $future | append . -}} {{- end -}} {{- end -}} {{- with $future }}
